# Supaluk Jaroensuk — Portfolio

A minimal dark portfolio built in Next.js 16 and React 19, showcasing engineering work at Spacely AI, VISAI AI and VISTEC.

## Overview

- **Index** — profile, selected Spacely AI work, current focus, performance metrics and toolkit
- **Work** — all 18 CV entries grouped by employer, with inline expandable detail, stack tags, links and screenshots
- **About** — career timeline, education, toolkit and contact

Work entries are sourced directly from the CV and expand inline — no separate project pages.

## CV

Full CV: [Google Drive](https://drive.google.com/file/d/1tt9gIWcgJEfDdXgCHvaZk77bH8kuU1pa/view?usp=drive_link)

## Stack

- **Framework:** Next.js 16
- **UI:** React 19, Tailwind CSS 4
- **Fonts:** DM Sans, JetBrains Mono
- **Interactivity:** native JS (expand/collapse, hash-based deep linking)

## Getting started

```bash
pnpm install
pnpm dev
```

The site runs on `http://localhost:3000`.

## Deploy

Built and optimized for production:

```bash
pnpm build
pnpm start
```
